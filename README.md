# Дом баланса

Персональный русскоязычный трекер на React, Vite и Firebase: закрытый вход для одного владельца, задачи, проекты, недельный трекер привычек, идеи, журнал размышлений, календарь, заметки, библиотека, цели, обзор недели, аналитика, архив, поиск и настройки.

## Быстрый запуск

1. Установите Node.js 20 или новее.
2. Выполните `npm install`.
3. Скопируйте `.env.example` в `.env.local` и заполните значения Firebase.
4. Запустите `npm run dev`.
5. Для production-проверки выполните `npm run build`.

Подробности — в [SETUP_FOR_OWNER.md](SETUP_FOR_OWNER.md).

## Безопасность

Firebase Web Config не является секретом. Доступ защищают Firebase Authentication, проверка `VITE_OWNER_UID` и серверные правила `firestore.rules`. Пароль, service account и закрытые ключи в репозиторий добавлять нельзя. Все данные находятся по путям `users/{uid}/...`; коллекции создаются автоматически.

## Future AI Assistant

AI намеренно не подключён. Доступ к данным отделён от интерфейса в `src/firebase/firestore.js`, поэтому позднее можно безопасно добавить серверного помощника без AI API-ключа в браузере.

Команды: `npm run dev`, `npm run lint`, `npm run build`, `npm run preview`.
